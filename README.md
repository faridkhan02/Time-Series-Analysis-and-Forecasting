## 🧠 What is Time Series Analysis?

A **time series** is a sequence of observations collected over time.

Examples include:

- ✈️ Monthly airline passengers
- 🪙 Gold prices
- 📈 Stock prices
- 🌡️ Temperature
- 🛒 Monthly sales
- ⚡ Electricity demand

Unlike ordinary tabular data, time series data has an important **time/order relationship** between observations.
